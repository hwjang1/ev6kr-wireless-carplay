# 다른 차종 지원 요청: 차량 정보 수집

이 프로젝트는 **국내형 기아 EV6**(내비 소프트웨어 `CVEV.KOR.0000.V039.001.260902`)에서만 확인했습니다. 다른 차종에서도 쓸 수 있는지 판단하려면 그 차의 정보가 필요합니다.

아래 순서로 차량 정보를 수집해 [GitHub 이슈](https://github.com/hwjang1/ev6kr-wireless-carplay/issues/new?template=car-info.yml)로 올려 주세요. 검토한 뒤 그 차가 대상이 되는지와 다음 단계를 이슈에 답변하겠습니다.

> [!NOTE]
> 개인 프로젝트라 지원을 약속하지는 못합니다. 답변까지 시간이 걸릴 수 있습니다. 저는 그 차에 직접 접근할 수 없어서, 대상이 되더라도 시험판 설치와 차량 시험, 로그 수집은 차 주인께서 해 주셔야 합니다.

## 대상이 될 수 있는 차

- 현대·기아·제네시스 차 중 **Gen5W 내비**를 쓰는 차. NEMESIS가 설치되는 차라면 Gen5W입니다.
- **순정 무선 카플레이가 없는** 국내형. 이미 무선 카플레이가 되는 차에는 필요 없습니다.
- 신형 인포테인먼트(ccNC)를 쓰는 차는 구조가 달라 대상이 아닙니다.

## 준비물

| 항목 | 필요 여부 |
|---|---|
| [NEMESIS](https://github.com/xwtk/hmg_nemesis) | **필요.** 순정 헤드유닛은 USB의 스크립트를 실행하지 않으므로 NEMESIS가 실행해 줍니다. 설치는 NEMESIS 안내를 따르며, 설치에 따른 책임은 본인에게 있습니다 |
| USB 메모리 | **필요.** FAT32나 exFAT로 포맷 |
| HMG-API | 필요 없음. 시스템 파일을 바꾸므로, 대상인지 확인되기 전에는 설치하지 마세요 |
| USB 무선랜 동글, usbwifi.hotspot | 필요 없음 |

## 1. USB 만들기

1. [최신 릴리스](https://github.com/hwjang1/ev6kr-wireless-carplay/releases/latest)에서 `ev6kr-carinfo-usb.zip`을 받습니다. 저장소의 [usb/carinfo/](../usb/carinfo/) 폴더에서 두 파일을 받아도 됩니다.
2. zip의 **내용물**(`NEMESIS.data`, `NEMESIS.sh`)을 USB 최상위에 풉니다. 폴더 안에 넣지 마세요.

## 2. 정보 수집

정차한 상태에서 합니다.

1. 데이터 USB 포트에 다른 장치(동글, USB 메모리)가 꽂혀 있으면 뺍니다.
2. 시동을 켜고, 내비 화면이 다 켜지면 만든 USB를 꽂습니다.
3. NEMESIS가 실행할지 물으면 "예"를 누릅니다.
4. 화면에 "차량 정보 수집 완료" 알림이 뜨면 USB를 뺍니다. 보통 1분 안에 끝납니다.

수집은 **읽기만 합니다.** 차의 설정이나 파일은 바꾸지 않습니다.

## 3. 결과 파일 확인

USB 최상위에 `CARINFO-<차종 코드>-<지역>.txt`가 생깁니다. 예를 들어 국내형 EV6는 `CARINFO-CVEV-KOR.txt`입니다.

| 들어 있는 것 | 들어 있지 않은 것 |
|---|---|
| 내비 소프트웨어 이름과 지역, 플랫폼 | 비밀번호, Wi-Fi 이름(SSID) |
| 설치된 NEMESIS 패키지와 버전 | 차대번호(VIN), 기기 시리얼 |
| 순정 Wi-Fi 모듈 유무 | 휴대폰 이름, 전화번호 |
| 카플레이 관련 순정 파일이 EV6와 같은지(파일 해시) | MAC·블루투스 주소 |
| 꽂혀 있는 USB 장치 종류, 저장 공간 | 위치, 주행 기록 |

올리기 전에 메모장 등으로 파일을 열어 내용을 확인해 주세요.

## 4. GitHub 이슈 등록

1. [차종 지원 요청 이슈](https://github.com/hwjang1/ev6kr-wireless-carplay/issues/new?template=car-info.yml)를 엽니다. GitHub 계정이 필요합니다.
2. 차종과 연식, 지금 카플레이 상태를 적습니다.
3. `CARINFO-….txt` 파일을 입력란에 끌어다 놓아 첨부합니다.

> [!WARNING]
> 이슈는 누구나 볼 수 있습니다. **결과 txt 파일만 올려 주세요.**
> - `CARINFO-FILES-…` 폴더의 파일은 올리지 마세요. 아래 [순정 파일 복사](#순정-파일-복사-요청받았을-때만)로 만든 제조사 파일입니다.
> - 다른 로그 수집 USB의 결과도 올리지 마세요. 휴대폰 이름이나 주소가 들어 있을 수 있습니다.
> - 차대번호가 보이는 사진도 올리지 마세요.

## 그다음

| 결과 | 다음 단계 |
|---|---|
| Gen5W가 아님(`[STOP]`) | 이 방식은 쓸 수 없습니다 |
| 순정 Wi-Fi 모듈이 있음 | 동글 없이 순정 기능을 쓰는 다른 방법이 더 맞을 수 있습니다 |
| 카플레이 파일이 EV6와 모두 같음 | 설치 조건과 차량 설정을 추가한 시험판을 만들 수 있습니다. 차 주인께서 설치하고 시험해 주셔야 합니다 |
| 다른 파일이 있음 | 그 파일을 분석해야 합니다. 이슈에서 따로 방법을 안내합니다 |

## 순정 파일 복사 (요청받았을 때만)

EV6와 다른 파일을 분석해야 할 때만 씁니다. USB 최상위에 빈 파일 `CARINFO-FILES`를 만들고 다시 수집하면, EV6와 다른 카플레이 파일을 `CARINFO-FILES-<차종 코드>-<지역>/` 폴더에 복사합니다.

이 파일들은 제조사 소프트웨어입니다. **이슈에 올리거나 공개하지 말고**, 이슈에서 안내하는 방법으로만 보내 주세요.

## 결과 직접 읽어 보기 (선택)

| 줄 | 뜻 |
|---|---|
| `[OK] Telechips tcc803x: a Gen5W head unit …` | Gen5W 플랫폼입니다 |
| `[STOP] platform … isn't a Gen5W one` | Gen5W가 아닙니다 |
| `[OK] Wi-Fi module variant 3: no stock Wi-Fi module …` | 순정 Wi-Fi 모듈이 없습니다(EV6와 같음). 동글 방식이 맞습니다 |
| `[WARN] the board reports a stock Wi-Fi module …` | 순정 Wi-Fi 모듈이 있습니다 |
| `[INFO] the car's Wi-Fi service didn't report its module variant …` | 순정 Wi-Fi 모듈 정보를 얻지 못했습니다. 그대로 이슈에 올려 주시면 됩니다 |
| `same` / `differs` / `missing` | 카플레이 관련 파일이 EV6와 같음 / 다름 / 없음 |
| `[OK] all 18 CarPlay files are the same as the EV6's …` | 카플레이 관련 파일이 모두 EV6와 같습니다 |
